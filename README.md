# Влияние приложения для медитации на время засыпания

Итоговый проект по теме «Постановка и проверка гипотез» (курс «Python для начинающих»).

**Цель:** проверить статистическими методами, сокращает ли использование приложения с вечерними медитациями время засыпания.

**Данные:** ~50 добровольцев, для каждого — возраст и среднее время засыпания (мин) за неделю до и за неделю после 4 недель использования приложения (парные данные). Данные генерируются ячейкой внутри ноутбука (фиксированный seed) и содержат имитацию ошибок выгрузки, которые очищаются в задании 2.

**Что сделано:** аудит и очистка данных с журналом, разведочный анализ, проверка нормальности, парный t-критерий (ручной расчёт + `scipy`), критерий Уилкоксона, сравнение с ошибочным непарным тестом, размер эффекта (Cohen's d), биномиальный тест доли улучшивших, бонус — сравнение возрастных групп.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook solution.ipynb  # затем Kernel → Restart & Run All
```

## Главный вывод

После 4 недель с приложением участники в среднем засыпают на **≈ 3.1 мин быстрее** (95% ДИ: 1.8–4.4 мин, ≈ 9% от исходного времени), быстрее стали засыпать ≈ 79% участников; вывод подтверждают три разных теста. Эффект сильнее у участников до 35 лет. Контрольной группы не было, поэтому причинный вывод требует рандомизированного исследования.
